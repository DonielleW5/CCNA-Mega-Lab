# Configuration Archive

This folder is reserved for sanitized Cisco IOS configuration snapshots from the lab.

## Planned Structure

```text
configs/
├── office-a/
│   ├── ASW-A1.txt
│   ├── ASW-A2.txt
│   ├── ASW-A3.txt
│   ├── DSW-A1.txt
│   └── DSW-A2.txt
├── office-b/
│   ├── ASW-B1.txt
│   ├── ASW-B2.txt
│   ├── ASW-B3.txt
│   ├── DSW-B1.txt
│   └── DSW-B2.txt
└── core-routing/
```

Actual configuration files can be added from Packet Tracer as the portfolio grows.

Before publishing configurations, remove or replace passwords, secrets, or other values that should not be public.
